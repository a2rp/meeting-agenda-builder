# Roomnote Meeting Agenda Builder

Roomnote helps a team prepare focused meetings with a timed agenda, clear owners, and a practical record of decisions.

## Run locally

```sh
npm install
npm run dev
```

## Check and deploy

```sh
npm run lint
npm run build
npm run deploy
```

The deployed site will be available at [https://a2rp.github.io/meeting-agenda-builder/](https://a2rp.github.io/meeting-agenda-builder/).
